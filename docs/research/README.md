# Research

Where the numbers this tool prints about somebody's baby came from, and how
hard they were argued with before they were allowed to stay.

- [`methodology.md`](methodology.md) is the reusable part: source tiers, the
  adversarial review protocol, the verdict vocabulary, and the rules for
  turning findings into something the tool will show. It is deliberately
  general. **Use it for the next topic too**, whether that is solids, growth,
  milestones, or anything else this tool ever asserts about a child.
- [`2026-09-30-reference-bands.md`](2026-09-30-reference-bands.md) is the first
  review: all four metrics in `data/reference.toml`, 19 bands, of which 4
  survived unchanged.

Two things to know before reading any of it.

**This research was done by a language model.** The protocol exists to make
that checkable rather than to make it authoritative. Every claim carries the
sentence it rests on, the body that published it and a URL, so a human can go
and look. That is the point of writing it down.

**The pediatrician outranks all of it.** These are ranges describing
populations, and no range describes a particular child. The tool says so on
every screen that prints one, and the README says it at greater length.
